# PotatOS; Systems Architecture

## Summary

PotatOS is a lightweight operating system designed for
optimal usage when it comes to heavy development from games
to AI and Quantum Computing, High speed and intelligent AI
Agents, and even lag-free high-speed gaming from Terraria,
WarFrame and even running modern games one has access to
which means you can play an XBox game that you have in your
possession.


### Spudgrams

The base OS contains a few pre-packaged lightweight
programs, and extra ones can be installed once within the
system. There are currently five planned programs, they are
as follows:

* **MaSH:** The main console/terminal instance to
communicate with the system itself.
* **SpudBrowser:** A internet browser that allows
web-surfing without the bloat.
* **SpudCode:** An extensive IDE for many type of
development from games to systems.
* **SpudGames:** A game center for one to relax after a
long tedious work day.
* **SpudNet:** The underlying AI system that boosts system
productivity when needed.


### System Model

The entire system mainly runs in TTY mode, but minimal
windows are able to be spawned for gaming, better web
viewing, or if you just want to have a GUI display of the
system itself.

Created with archiso originally, but it is planned to be
completly rewritten into its own system so it can be its
own thing and not just piggy-backing off of an existing
successful system.
